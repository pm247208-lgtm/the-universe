# THE UNIVERSE – KHÁM PHÁ VŨ TRỤ BAO LA

## 1. Giới thiệu dự án

THE UNIVERSE là website giới thiệu và cung cấp thông tin cơ bản về vũ trụ. Website giúp người xem khám phá các kiến thức về hệ Mặt Trời, thiên hà, các hiện tượng bí ẩn và hoạt động khám phá không gian.

## 2. Mục tiêu

- Cung cấp thông tin khoa học về vũ trụ.
- Giúp người xem tìm hiểu các hành tinh và thiên hà.
- Xây dựng giao diện trực quan, dễ sử dụng.
- Hỗ trợ hiển thị trên máy tính và điện thoại.

## 3. Công nghệ sử dụng

- HTML5: Xây dựng cấu trúc website.
- CSS3: Thiết kế giao diện và bố cục responsive.
- JavaScript: Hỗ trợ các chức năng tương tác cơ bản.
- Visual Studio Code: Soạn thảo mã nguồn.
- Git và GitHub: Quản lý và lưu trữ mã nguồn.
- GitHub Pages: Triển khai website trực tuyến.

## 4. Cấu trúc dự án

- index.html: Trang chính của website.
- css/style.css: Tệp định dạng giao diện.
- js/script.js: Tệp xử lý JavaScript.
- images/: Thư mục lưu trữ hình ảnh.

## 5. Các nội dung chính

- Trang chủ và giới thiệu tổng quan về vũ trụ.
- Hệ Mặt Trời và 8 hành tinh.
- Thiên hà và các ngôi sao.
- Những bí ẩn của vũ trụ.
- Hoạt động khám phá không gian.
